AGENTS.md documentation-impact checks tend to catch the Project Structure tree and new-module bullets while missing the Architecture section's per-subsystem responsibility bullets. When a change adds a behavior class to an existing subsystem (for example, a new tool-guard block reason), extend that subsystem's enumerated architecture bullet in the same change — the structure tree alone does not describe responsibilities.
