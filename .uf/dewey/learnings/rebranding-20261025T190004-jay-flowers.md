Rebrand changes that introduce a roadmap identity need a package-metadata checkpoint: package.json descriptions and keywords tend to adopt the future identity without the current-vs-roadmap qualifiers the README carefully carries (e.g., 'consoles for agent self-serve tools and engineer directives' listed as shipped components while the consoles are roadmap items). Add package.json to the rename verification checklist alongside README/AGENTS/CHANGELOG, checking every enumerated capability against shipped code.
